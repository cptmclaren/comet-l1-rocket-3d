# Comet L1 Rocket — interactive 3D model

Live: https://cptmclaren.github.io/comet-l1-rocket-3d/

Generated from the team's OpenRocket design (`L1_H135W.ork`): every component's position and size comes from the model.
Drag to orbit, right-drag to pan, scroll to zoom, click a part to see what it is, why it's there and how it's mounted.
